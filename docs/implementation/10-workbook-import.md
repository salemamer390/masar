# استيراد ملف الموظفين

**المصدر:** `Tazamun Egypt توظيف -.xlsx`  
**تاريخ الفحص:** 7 أكتوبر 2026

## نتيجة الفحص

- شيت **بيانات الموظفين** يحتوي صف موظف فعلي واحد: الكود `101` والاسم `عامر`.
- شيتات الحضور والإجازات والجزاءات لا تحتوي صفوف بيانات فعلية، لذلك لا تُنشأ منها أي سجلات تشغيلية.
- أنشئ الأمر `tazamun:import-employees` لقراءة شيت الموظفين مباشرة من XLSX دون الاعتماد على برنامج Excel.

## قواعد الاستيراد

- الكود هو مفتاح الاستيراد الأساسي؛ يعاد تحديث الموظف عند تكرار الكود.
- ينشئ القسم أو الوظيفة أو الحالة المرجعية إن لم تكن موجودة.
- لا يكتب راتبًا أو حضورًا أو إجازة أو جزاءً غير موجود في المصدر.
- بيانات لا يقابلها حقل تشغيلي مباشر، مثل الرصيد اليدوي وساعات الدوام الخاصة، تحفظ كملاحظة مصدرية ولا تتحول تلقائيًا إلى قاعدة عمل.
- يسجل كل إنشاء أو تحديث في Audit Log.

## تنفيذ الاستيراد الحالي

- تم تحديث 7 سجلات موظفين قائمة ومطابقة برقم الهوية، ولم تُنشأ نسخ مكررة.
- تم إنشاء أو تحديث 7 هياكل رواتب بصافي الرواتب الوارد في البيانات.
- تم الاحتفاظ بإجمالي البدلات كما ورد كمبلغ بدلات مؤقت يحتاج توزيعًا معتمدًا على البنود الأربعة.
- لم تُدخل تواريخ نهاية العقد التي كانت أسبق من تاريخ بدايته؛ سُجلت كملاحظة للمراجعة.
- تم حذف ملف البيانات المؤقت بعد الاستيراد حتى لا تبقى بيانات الهوية والبريد والهاتف داخل مساحة المشروع.
