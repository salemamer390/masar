# المرحلة 2: نواة الموظف وملف الموظف

**الحالة:** منفذة جزئيًا  
**تاريخ التنفيذ:** 7 أكتوبر 2026

## النطاق المنفذ

استكمال البيانات المرجعية الناقصة من ملف الموظف: اتصال الطوارئ والحساب البنكي، مع الاحتفاظ بالسجل الزمني للحسابات وربط كل قيمة بمفاتيح خارجية.

## ما نُفذ

1. أُنشئت الجداول التالية عبر migration `2026_10_06_225000_create_employee_contact_and_bank_tables`:
   - `banks`: بيانات البنوك المرجعية مع كود وحالة نشاط.
   - `employee_emergency_contacts`: الاسم والهاتف وصلة القرابة وعلامة جهة الاتصال الأساسية.
   - `employee_bank_accounts`: البنك، الحساب، IBAN، طريقة الصرف، فترة السريان، الحالة وعلامة الحساب الأساسي.
2. جميع العلاقات مربوطة بمفاتيح خارجية إلى الموظف والبنك وطريقة الصرف، مع فهارس على حقول الاستعلام والتاريخ.
3. أضيفت Models وعلاقات Eloquent لبيانات الطوارئ والحسابات البنكية في `Employee`.
4. أضيفت عمليتا حفظ محميتان بصلاحية `employees.edit`:
   - `POST /employees/{employee}/emergency-contacts`
   - `POST /employees/{employee}/bank-accounts`
5. يتم إلغاء علامة الحساب/جهة الاتصال الأساسية السابقة داخل DB transaction عند اختيار سجل أساسي جديد.
6. أضيفت سجلات Audit Log عند إنشاء جهة اتصال أو حساب بنكي.
7. أضيفت بيانات العرض والإضافة في تبويب النظرة العامة لملف الموظف.

## معالجة حدث الترحيل

أثناء تنفيذ migration حصل توقف بعد وجود جدول `banks` وقبل تسجيل migration. لم يتم حذف أي جدول أو بيانات. تم تعديل migration لتكون idempotent (`Schema::hasTable`) ثم شغلت بنجاح في batch 4. هذا يمنع فشلها عند إعادة المحاولة إذا وُجد جدول أُنشئ في محاولة سابقة.

## التحقق

- فحص PHP للـ models والـ migration والـ controllers ناجح.
- `php artisan migrate --pretend` نجح قبل التطبيق.
- `php artisan migrate --force` نجح؛ migration مسجلة في batch 4.
- `php artisan route:list --name=employees.` أكد مساري الحفظ.

## أعمال متبقية للمرحلة 2

- توسيع نموذج الموظف للهوية (الإصدار/الانتهاء/مكان الإصدار)، الجنسية، التجنيد، الصورة والبريد الوظيفي.
- استبدال رصيد الإجازة الثابت في ملف الموظف بحساب مبني على نوع الإجازة وسياسة الاستحقاق.
- إضافة تعديل/أرشفة منضبط لجهات الاتصال والحسابات البنكية بدل الإضافة فقط.
- إنشاء واجهة Master Data للبنوك وحقول التحقق المتخصصة للـ IBAN والرقم القومي.
