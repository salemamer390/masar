# المرحلة 9 — الجودة والإطلاق

**الحالة:** قيد التنفيذ.
**التاريخ:** 7 أكتوبر 2026

## تحقق منفذ

- نجح `php -l` للـ Controllers المعدلة في الحضور والرواتب والإجازات ولوحة التحكم.
- تمت مراجعة مسارات الإجازات ومسارات تشغيل الرواتب أثناء التنفيذ.
- migrations الجديدة شُغلت سابقًا بنجاح وسجلّها ظاهر في حالة migrations.

## مانع الإطلاق

- بيئة المشروع لا تحتوي `vendor/bin/phpunit` ولا يوفر Artisan أمر `test`، ولذلك لا توجد نتيجة اختبار آلية يمكن اعتمادها للإنتاج.

## بوابة الإطلاق

1. تثبيت وتشغيل PHPUnit أو Pest.
2. اعتماد حالات UAT رقمية للراتب والضريبة والتأمين والإضافي والغياب.
3. تجربة backup وrestore في بيئة منفصلة.
4. مراجعة أمنية للملفات والتصدير والصلاحيات وسجل التدقيق.
5. إعداد runbook شهري لمسير الرواتب، القفل، والتصحيحات.
