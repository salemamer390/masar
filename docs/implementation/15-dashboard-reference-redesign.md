# إعادة تصميم لوحة التحكم وفق المرجع المرئي

**تاريخ التنفيذ:** 07-10-2026  
**الهدف:** تحويل لوحة التحكم إلى لوحة تشغيل يومية مستلهمة من المرجع المرفق، دون إدخال أرقام أو عناصر تجريبية.

## المكونات المنفذة

- شريط إجراءات سريع يظهر بحسب صلاحيات الإنشاء الفعلية: موظف جديد، إجازة، حضور، جزاء، دورة رواتب، حركة وظيفية، وتقارير.
- بطاقات مؤشرات ديناميكية للموظفين، الحضور، الإجازات، صافي الرواتب، وتكلفة الشركة.
- قائمة الطلبات المعلقة من طلبات الإجازات الحقيقية فقط.
- قائمة المواعيد المهمة من العقود والمستندات التي تنتهي خلال 30 يومًا.
- ملخص حالة الحضور لهذا اليوم من جدول `attendance` بدون افتراض غياب غير مسجل.
- حالة المستندات من جدول `documents`.
- آخر الإجازات المعتمدة، وملخص آخر دورة رواتب، وأحدث الموظفين وفق تاريخ التعيين.
- قائمة متابعة تظهر فقط عند وجود تنبيه حقيقي.

## التفاعل والصلاحيات

- كل بطاقة وقائمة وزر تنقل إلى الوحدة أو السجل المرتبط فعليًا.
- لا يجري الاستعلام عن وحدة لا يمتلك المستخدم صلاحية عرضها.
- أزرار الإنشاء لا تظهر إلا عند صلاحية الإنشاء المناسبة.
- لا يوجد زر «إذن» مستقل لأن النظام لا يملك بعد وحدة أو workflow للإذن؛ لم تتم محاكاة وظيفة غير موجودة.

## الأداء

- استخدمت aggregation و`limit(5)` للقوائم القصيرة.
- جميع بطاقات اللوحة تعتمد على البيانات المخزنة، ولا يوجد Mock Data أو أرقام ثابتة.
- تم الحفاظ على التصميم المتجاوب وRTL عبر طبقة CSS مشتركة.

## التحقق

- نجح فحص PHP syntax لـ `DashboardController` وBlade الخاص بلوحة التحكم.
- تم التحقق من Route لوحة التحكم.
