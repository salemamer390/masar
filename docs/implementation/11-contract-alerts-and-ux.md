# العقود والإشعارات وترقية تجربة الاستخدام

**تاريخ التنفيذ:** 7 أكتوبر 2026

## العقود

- صححت migration تواريخ نهاية عقود الموظفين التي تبدأ في 2026 لتصبح سنة 2027، بنهاية اليوم السابق لمرور سنة من تاريخ البداية.
- لا تمس migration الرواتب أو مسيرات الرواتب أو هوية الموظف.

## تنبيهات انتهاء العقد

- أضيف جدول Laravel database notifications.
- الأمر `tazamun:send-contract-alerts --days=30` ينشئ تنبيهًا للمستخدمين المخولين بعرض الموظفين عند بقاء 30 يومًا أو أقل على انتهاء العقد.
- يمنع التكرار اليومي للتنبيه لنفس الموظف والمستخدم.
- أضيف الأمر للجدولة اليومية الساعة 08:00؛ يتطلب الإنتاج تشغيل Laravel scheduler المعتاد.
- تظهر التنبيهات في زر الجرس وتنتقل إلى ملف الموظف عند فتحها.

## الواجهة

- نقلت صفحة إعدادات الرواتب إلى عنصر مستقل باسم **الإعدادات** أسفل **التقارير** في القائمة الجانبية.
- تجمع صفحة الإعدادات ملخص هياكل الرواتب، رابط الهياكل، نسب الحساب، توزيع البدلات، وسجل التعديلات.
- أضيفت مؤشرات حقيقية للموظفين والعقود في صفحات الموظفين والبيانات الوظيفية ولوحة التحكم.
- أضيفت طبقة UX مشتركة للاستجابة، حالات الجداول، الإشعارات، النماذج، الوضع الداكن، والهواتف دون تغيير صلاحيات أو عمليات النظام.
