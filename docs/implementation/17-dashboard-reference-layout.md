# Dashboard Reference Layout

## الهدف

تمت إعادة بناء لوحة التحكم لتتبع التكوين المعتمد: شريط علوي مدمج، صف إجراءات سريعة، ستة مؤشرات رئيسية، ثم ثلاثة أعمدة تشغيلية ثابتة.

## الربط بالبيانات

- مؤشرات الموظفين والحضور والغياب والتأخير والإجازات والرواتب تُحمّل من قاعدة البيانات وبحسب صلاحية المستخدم.
- الطلبات، المواعيد المهمة، المستندات، الموظفون الجدد، والإجازات المعتمدة تعرض سجلات حقيقية مع روابط مباشرة إلى مصدرها.
- أزرار الإجراءات تفتح الوظائف الموجودة بالفعل فقط؛ رفع المستند يفتح إدارة المستندات، ولا ينشئ نموذجاً وهمياً.

## التوافق

- التخطيط يدعم RTL ويثبت الأعمدة بصرياً كما في المرجع.
- ينتقل إلى صفوف ثم عمود واحد على الشاشات الأصغر دون فقد المعلومات أو الإجراءات.
- يوجد ملف CSS مخصص للوحة التحكم فقط: `public/dashboard-reference.css`، لذلك لا تتأثر بقية الصفحات بهذا التخطيط.

## التحقق

تم تنفيذ `php artisan view:cache` والتحقق من صياغة `DashboardController.php` بنجاح.
