# المرحلة 8 — التقارير ولوحة التحكم

**الحالة:** منفذة جزئيًا.
**التاريخ:** 7 أكتوبر 2026

## المنفذ

- لوحة التحكم تعرض مؤشرات محفوظة في قاعدة البيانات فقط: الموظفون، الموظفون النشطون، هياكل الرواتب، الإجازات، صافي مسير الشهر وتكلفته، وآخر Payroll Run.
- إزالة أمثلة الأنشطة والأرقام الافتراضية من لوحة التحكم؛ تظهر حالة فارغة صريحة عند عدم وجود سجلات.
- صفحة التقارير تحتوي بطاقات فعلية لتقارير الموظفين والحضور وهياكل الرواتب ومسير الرواتب والإجازات والتأمينات والملخص الإداري.
- تقرير `payroll` يعرض سجلات الرواتب المعتمدة أو المقفلة فقط ويدعم التصدير عبر البنية الحالية.
- واجهات الحضور والإجازات أصبحت تعرض حالة المصدر/الاعتماد وتدعم الانتقال التشغيلي من الواجهة حسب الصلاحية.

## المتبقي

- فلاتر موحدة بالتاريخ والموظف والقسم والفرع في كل التقارير.
- تنبيهات العقود وفترة التجربة والمستندات والتأمين من مصادر تاريخية معتمدة.
- اختبار صلاحيات التصدير ونطاق البيانات لكل دور.
