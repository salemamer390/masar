# المرحلة 5 — الحضور والإجازات والإضافي والجزاءات

**الحالة:** منفذة جزئيًا.
**التاريخ:** 7 أكتوبر 2026

## المنفذ

- سجل الحضور يدعم المصدر وحالة الاعتماد `Draft` أو `Approved` والمستخدم وتاريخ الاعتماد.
- واجهة الحضور تعرض المؤشرات الفعلية وحالة المصدر والاعتماد، ولا تستخدم أرقامًا افتراضية.
- الإجازات تمر بالدورة: `Pending → Manager Approved → Approved`، مع الرفض من أي مرحلة معلقة وسجل تدقيق لكل انتقال.
- مسير الرواتب يستهلك سجلات الحضور المعتمدة فقط: الغياب، دقائق الإضافي، والإجازات المعتمدة كسجل مرجعي؛ كما يستهلك الجزاءات المغلقة في الشهر.
- تحفظ نتيجة Payroll معرفات السجلات المصدرية والقيم المشتقة داخل `calculation_snapshot`.
- أضيفت خدمة `PayrollPeriodGuard`: تمنع على الخادم إنشاء أو اعتماد أو رفض أو حذف حضور أو إجازة أو جزاء يقع داخل شهر Payroll مقفل.

## التحقق

- نجح فحص PHP لخدمة الحراسة ولـ Controllers الحضور والإجازات والجزاءات.
- لا توجد بيانات رواتب تجريبية تم إنشاؤها في قاعدة البيانات الحية.

## المتبقي

- Workflow مستقل لاعتماد الإضافي والجزاءات قبل الإقفال بدل اعتبار الإغلاق اعتمادًا للجزاء.
- سياسة رصيد الإجازات والاستحقاق حسب النوع ومدة الخدمة.
- Adjustment workflow مصرح به لتصحيح المدخلات بعد إقفال المسير.
